# چاپینو — مدیریت مرکز کپی و چاپ

چاپینو یک نرم‌افزار فارسی و راست‌چین برای صدور فاکتور آزاد، مدیریت مشتریان، دفتر حساب و گزارش بدهکاران است. رابط به‌صورت وب‌اپ محلی طراحی شده و می‌تواند در شبکه داخلی یا داخل یک پوسته دسکتاپ اجرا شود. هیچ کالا یا خدمت پیش‌فرضی در سیستم ثبت نمی‌شود.

## امکانات

- داشبورد فروش امروز و ماه، مشتریان و مطالبات
- شماره فاکتور شمسی با ریست سالانه (`1405-0001`)
- اقلام نامحدود با شرح، تعداد، واحد آزاد و قیمت دستی
- ثبت واریزی مشتری به‌عنوان ردیف مستقل داخل فاکتور
- محاسبه جمع فروش، مانده قبلی و مانده نهایی
- مبلغ به حروف فارسی و نمایش ارقام فارسی
- مشتریان، صورت‌حساب کامل و مانده لحظه‌ای
- دفتر بدهکار/بستانکار با فیلتر تاریخ شمسی
- گزارش بدهکاران و خروجی چاپ/PDF
- فاکتور برندمحور A4 و قالب HTML مستقل
- تم روشن و تاریک، پالت رنگ، لوگو و اطلاعات تماس
- فونت آفلاین Vazirmatn

## ساختار ماژول‌ها

- `src/app/page.tsx`: نقطه ورود برنامه
- `src/components/app-shell.tsx`: پوسته، سایدبار، ناوبری و همگام‌سازی API
- `src/components/sections/`: صفحات داشبورد، فاکتور، مشتریان، دفتر، گزارش و تنظیمات
- `src/components/invoice-paper.tsx`: نسخه واحد پیش‌نمایش و چاپ فاکتور A4
- `src/app/api/app/route.ts`: عملیات کامل داده‌ها و محاسبات حسابداری
- `src/db/schema.ts`: مدل Drizzle جداول تنظیمات، مشتری، فاکتور، اقلام و دفتر
- `src/lib/format.ts`: تاریخ شمسی، ارقام فارسی، تومان و مبلغ به حروف
- `src/app/globals.css`: طراحی کامل، تم تاریک، واکنش‌گرایی و چاپ A4
- `public/invoice_template.html`: قالب HTML مستقل برای شخصی‌سازی آسان

## نصب روی Windows 11

### پیش‌نیازها

1. Node.js نسخه 20 یا جدیدتر
2. PostgreSQL نسخه 15 یا جدیدتر
3. Git (اختیاری)

### راه‌اندازی

1. وابستگی‌ها را نصب کنید:
   `npm install`
2. فایل `.env` را ایجاد و اتصال دیتابیس را تنظیم کنید:
   `DATABASE_URL=postgresql://postgres:postgres@127.0.0.1:5432/app_db`
3. جداول را بسازید:
   `npx drizzle-kit push`
4. اجرای توسعه:
   `npm run dev`
5. مرورگر را در `http://localhost:3000` باز کنید.

### اجرای تولیدی

1. `npm run build`
2. `npm run start`

برای اجرای تمام‌صفحه در Windows می‌توان برنامه را از Microsoft Edge با گزینه **Apps > Install this site as an app** نصب کرد؛ در این حالت مانند یک نرم‌افزار دسکتاپ مستقل اجرا می‌شود.

## ساخت بسته دسکتاپ (Setup.exe)

پوسته دسکتاپ Electron و اسکریپت‌های ساخت نصاب ویندوز در پوشه `desktop/` آماده است. راهنمای کامل گام‌به‌گام: **`SETUP-WINDOWS.md`**

خلاصه: روی ویندوز ابتدا `desktop\db-setup.bat` (یک بار) و سپس `desktop\build-setup.bat` را اجرا کنید؛ خروجی `desktop\dist-setup\Chapino-Setup-1.0.0.exe` با ویزارد نصب و میان‌بر دسکتاپ ساخته می‌شود.

## چاپ و PDF

در پیش‌نمایش فاکتور یا گزارش، «چاپ / ذخیره PDF» را انتخاب کنید. در پنجره چاپ Windows مقصد **Save as PDF** یا چاپگر فیزیکی را برگزینید. اندازه کاغذ A4، حالت عمودی و چاپ رنگ پس‌زمینه در CSS تثبیت شده است.

## نکات حسابداری

- عدد مثبت مانده یعنی مشتری بدهکار است.
- عدد منفی مانده یعنی مشتری بستانکار است.
- ذخیره فاکتور یک رویداد خودکار با بدهکار برابر جمع فروش و بستانکار برابر واریزی‌ها در دفتر ایجاد می‌کند.
- تراکنش خودکار تنها با حذف فاکتور پاک می‌شود؛ تراکنش‌های دستی مستقلاً قابل حذف‌اند.
- مشتری دارای فاکتور برای حفظ سوابق مالی قابل حذف نیست.
- همه مبلغ‌ها به تومان و به‌صورت عدد صحیح ذخیره می‌شوند.
